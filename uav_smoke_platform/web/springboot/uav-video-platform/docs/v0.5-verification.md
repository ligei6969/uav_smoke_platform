## Media Proxy and Duplicate Protection

The annotated-video proxy preserved FastAPI's byte-range response. The
annotated MP4 is now encoded as H.264/AVC (`avc1`) for HTML5 playback; a
successful `206 Partial Content` response alone is not considered proof that a
browser can decode the file.

```text
GET /media/videos/{videoId}/analysis/annotated
Range: bytes=0-1023

HTTP 206
Content-Type: video/mp4
Content-Length: 1024
Content-Range: bytes 0-1023/144736873
Accept-Ranges: bytes
```

The maximum-confidence keyframe and detection JSON returned HTTP 200 with
`image/jpeg` and `application/json` respectively. A second start request for
the completed video returned HTTP 409 and did not create a duplicate task.

## Failure and Retry

A second real video (`16.mp4`) was submitted while FastAPI was deliberately
stopped:

```text
POST /api/videos/{videoId}/analysis -> HTTP 503
persisted status                    -> FAILED
persisted error                     -> 无法连接烟雾分析服务
```

After FastAPI restarted, `POST /api/videos/{videoId}/analysis/retry` created a
new attempt without re-uploading the video. It progressed through PENDING and
RUNNING to COMPLETED. The failed attempt remains in the database as history.

## Restart Recovery

Spring Boot was stopped and restarted with the same MySQL database. The latest
completed result, statistics, and media URLs were returned directly from the
persisted record.

FastAPI was then restarted, clearing its in-memory task map. The completed
artifact remained accessible from its task output directory, and the Spring
Boot annotated-video proxy still returned HTTP 206 with the correct byte range.

## UI Verification Note

The detail page, static JavaScript, API endpoints, and media assets returned
HTTP 200 in the running application. The current automation session did not
have a connected browser instance, so screenshot-based visual inspection was
not available. As a transport-and-decoding check, FFmpeg read the versioned
Spring Boot media URL, sought to 3.4 and 120 seconds, and decoded valid frames;
the 3.4-second frame contained the expected smoke bounding box and confidence
label. The application remained available locally for manual review.
